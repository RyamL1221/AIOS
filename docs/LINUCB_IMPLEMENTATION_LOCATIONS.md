# LinUCB Implementation Locations (Confirmed)

Read-only investigation establishing ground truth on where the adaptive
memory-threshold LinUCB bandits live and how arm selection is computed,
before any code changes. All paths and line numbers below were verified
against the working tree.

## Summary of Confirmed Locations

### (a) `PolicyManager` class definition
- **File:** `aios/memory/policy.py`
- **Line:** 389 (`class PolicyManager:`)
- `__init__` at line ~466; the three bandits are constructed at
  `aios/memory/policy.py:474` via the `self._bandits` dict comprehension.

### (b) The three LinUCB bandit instantiations
- **File:** `aios/memory/policy.py`
- The bandits are **not** three separate hand-written instantiations.
  A single reusable `LinUCBBandit` class (defined at
  `aios/memory/policy.py:169`) is instantiated once per entry in
  `PolicyManager.ACTION_SPACES` (defined at `aios/memory/policy.py`,
  the `ACTION_SPACES` dict) inside the `self._bandits` comprehension at
  `aios/memory/policy.py:474-482`.
- The three bandit names / action spaces:
  - `novelty_threshold` — add gate (admit iff max-sim-to-existing < T)
  - `similarity_threshold` — retrieve relevance gate (keep iff sim >= T)
  - `redundancy_threshold` — retrieve dedup gate (drop iff pairwise > T)

### (c) Reward-ingestion point

- **Bandit update call:** `self.policy.update(...)` at

- **Syscall routing:** `ReportRewardQuery` is matched explicitly in

### (d) UCB score computation (mean estimate + exploration bonus)
- **File:** `aios/memory/policy.py`
- **Method:** `LinUCBBandit.arm_scores`, defined at
  `aios/memory/policy.py:259`.
- The per-arm score is `mean + alpha * bonus`, where:
  - `A_inv = np.linalg.inv(self._A[a])`
  - `theta = A_inv @ self._b[a]`
  - `mean = float(theta @ x)` — the exploitation term
  - `bonus = self.alpha * float(np.sqrt(x @ A_inv @ x))` — the UCB
    exploration bonus
- `select_arm` (`aios/memory/policy.py`, ~line 305) takes `argmax` of
  `arm_scores` (ties break to lowest index).
- `arm_mean_estimates` (`aios/memory/policy.py`, ~line 285) exposes the
  exploitation term alone for inspecting learning without the bonus.
- Reward normalization (`r / JUDGE_MAX_SCORE`, `JUDGE_MAX_SCORE = 5.0`)
  happens in `PolicyManager.update` at `aios/memory/policy.py:576`
  before reaching `LinUCBBandit.update` at `aios/memory/policy.py:323`.

### (e) Current alpha value and where it is configured

## Divergences from the Master Prompt's Assumptions

1. **`PolicyManager` is NOT in `aios/memory/manager.py`.** The master
   prompt's subtask assumed `manager.py` is "the likely home". In
   reality, both `PolicyManager` and `LinUCBBandit` live in a dedicated
   module, `aios/memory/policy.py`. `manager.py` only *consumes*
   `PolicyManager` (lazy-imported at `aios/memory/manager.py:145` inside
   the `_adaptive_enabled` branch) and owns the reward-ingestion glue
   (`report_reward`).

2. **The three bandits are not three explicit instantiations.** They are
   generated by a dict comprehension over `PolicyManager.ACTION_SPACES`,
   all using the same `LinUCBBandit` class. There is one class, three
   configured instances.

3. **`report_reward` is a kernel-side schema, not an SDK
   `MemoryQuery`.** `ReportRewardQuery` lives in `aios/memory/schemas.py`
   and is matched by `isinstance` type-checks in the syscall path
   because the SDK's `MemoryQuery.operation_type` Literal cannot
   represent `"report_reward"`. Over HTTP it uses the dedicated
   `POST /memory/report_reward` endpoint rather than `/query`.

4. **`static_thresholds.py` is not involved in the bandit config.** It
   is the separate, mutually-exclusive fixed-threshold gating variant
   and holds no LinUCB/bandit state. Bandit alpha and action spaces are
   entirely in `policy.py` + `config.yaml`.

## Note on ACTION_SPACES (context for later subtasks)

The action spaces in `PolicyManager.ACTION_SPACES` were extended
downward (commit `b6ffd7e`): `similarity_threshold` has 11 arms
(`0.0`-floor), `novelty_threshold` and `redundancy_threshold` have 10
arms each (`0.1`-floor). This supersedes the 6-arm/`0.50`-floor spaces
described in older docs. See `aios/memory/policy.py` `ACTION_SPACES` for
the authoritative current values.
